## `[ SYSTEM_BRIEFING ]`

> **BountyLine** es un sistema de gestión de cazarrecompensas desarrollado como proyecto final de **Bases de Datos 2**.
> Combina una base de datos **relacional (MySQL)** con una **no relacional (MongoDB)** para rastrear objetivos, contratos y recompensas en las calles digitales de la red.

---

## `[ ARQUITECTURA_DEL_SISTEMA ]`

Para mantener el código **organizado, limpio y modular**, el repositorio usa una estrategia de ramas independientes, una por cada capa de la aplicación.

### 🟣 `main` :: NÚCLEO DE PRODUCCIÓN
Rama estable y consolidada. Aquí se integran las demás ramas una vez verificadas y probadas en el entorno local.

### 🔷 Ramas de desarrollo

| Módulo | Rama | Contenido | Comando de acceso |
| :--- | :---: | :--- | :--- |
| 🖥️ **Interfaz** | `frontend` | UI, componentes visuales, estilos y lógica del cliente | `git checkout frontend` |
| ⚙️ **Servidor** | `backend` | Lógica del servidor, API, rutas y controladores | `git checkout backend` |
| 🗄️ **Datos** | `bd` | Scripts de inicialización, migraciones, modelos y diagramas de la base de datos híbrida | `git checkout bd` |

```bash
# >>> ACCEDER A UN MÓDULO
git checkout backend    # ⚙️  servidor / API
git checkout frontend   # 🖥️  interfaz
git checkout bd         # 🗄️  base de datos
```
